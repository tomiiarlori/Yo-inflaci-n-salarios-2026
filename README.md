# Simulador de salarios e inflación

Proyecto recuperado desde la versión guardada `app_trabajo_final.py`. Datos de IPC diciembre 2025 a septiembre 2026, empleados en el trabajo original.

## Archivos
- `app.py`: aplicación Streamlit.
- `requirements.txt`: dependencias necesarias.

## Publicación en Streamlit Community Cloud
Subir ambos archivos a la raíz de un repositorio GitHub accesible por Streamlit, elegir rama `main` y archivo principal `app.py`.

## Ejecución local
`pip install -r requirements.txt`
`streamlit run app.py`
