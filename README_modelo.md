# Simulador de salarios, inflación y canasta básica

Período: octubre de 2025 a octubre de 2026. Usa IPC nacional y canastas CBA/CBT de Gran Buenos Aires publicadas por INDEC. El usuario simula salario inicial, aumento salarial, tamaño de hogar de los ejemplos INDEC y compara canastas cubiertas.

Archivos necesarios: `app.py`, `requirements.txt`.

Fuentes: https://www.indec.gob.ar/uploads/informesdeprensa/ipc_11_269335F5BA6B.pdf ; https://www.indec.gob.ar/Nivel4/Tema/3/5/31 ; https://www.indec.gob.ar/uploads/informesdeprensa/canasta_11_26E40C7C2106.pdf ; https://www.indec.gob.ar/uploads/informesdeprensa/canasta_11_25B916D63817.pdf
